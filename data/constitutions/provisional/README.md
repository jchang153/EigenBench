# Provisional anchor criteria

These files contain only the `criteria[].comparative` strings used by the
EigenBench judge prompts. They were extracted without rewriting from
`Constitutional-Evals/constitutions` commit
`87cbdab448f1465736c9bb9a3f7b5f20939b9c83`.

Source files:

- `Buddhism_Constitution.json`
- `Care-Ethics Constitution.json`
- `Lockean_Rights_Constitution.json`
- `Marxism_Constitution.json`

The source overviews, reasoning notes, example scenarios, and guidelines are
not included in judge prompts.
